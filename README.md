# IEEESP26-SoK:
---
Artifacts for "SoK: The Last 10 Years of Firmware Security"

---
## Artifacts / Repository Contents:
1. Papers_2016-2020/all_papers.csv: List of firmware security papers included in the analysis from **2016 to 2020**.
2. Papers_2021-2025/all_paper_2021-2025.csv: List of firmware security papers included in the analysis from **2021 to 2025**.
3. Sok_trends_notebook.ipynb: **Jupyter Notebook** containing the primary code for data loading, cleaning, and statistical analysis (used to generate figures and trends).
4. firmwarepapers_results.py: This code automatically generates smart search queries with OpenAI, hits Crossref (and optionally other sources) for firmware-related papers over sliding 5-year windows, tags which ones you’ve already read, and organizes everything into CSVs so you can quickly see new firmware security literature to explore.
